# NegPy 0.65.0 简体中文 · Apple Silicon 优化版：改动与优化说明

基于 NegPy 0.65.0 正式版加上游官方多语言支持（提交 0dc536a8），界面中文来自官方语言包。下面所有优化只在 Apple 芯片（M1/M2/M3/M4 及更新）上生效，或者在所有平台上结果都与官方版逐位一致。**调色算法和出片结果没有任何改动。**

实测机器：MacBook Pro M1 Max，64 GB 内存；测试文件为 9600 万像素松下 RW2、徕卡 M11 DNG、索尼 ARW。

## 一、速度对比（M1 Max 64 GB）

| 操作 | 官方版 | 优化版 |
|---|---|---|
| 高质量预览打开一张 9600 万像素 RW2 | 3.86 秒 | 1.09 秒 |
| 高质量预览下切到下一张（已预读） | 1.1～1.4 秒 | 立即（0 毫秒，像素相同） |
| 打开三色扫描组合 | 11.4 秒 | 2.5 秒；被预读后切过去为立即 |
| 拖动滑块后松手 | 0.60 秒 | 0.26 秒 |
| 首次渲染 | 2.19 秒 | 1.51 秒 |
| 导出 JPEG（9600 万像素） | 5.23 秒 | 2.17 秒 |
| 16 位 TIFF（ZIP 压缩）编码 | 6.14 秒 | 0.83 秒 |
| 徕卡 M11 DNG 编码 | 3.45 秒 | 0.47 秒 |
| CPU 渲染路径 | 单核 | 多核，约快 7 倍 |

## 二、具体改动

### 1. RAW 解码改为多核
官方 Mac 版的 RAW 解码库（LibRaw）没有开启多线程，只用 1 个 CPU 核心。本版用同一份 LibRaw 源码开启 OpenMP 重新编译，多线程运行库（libomp）作为动态库随 App 附带，不需要另外安装任何东西。
（修复记录：第一版在实际使用中会偶发闪退或卡住，原因有两个，均已修复并通过多线程压力测试：
① libomp 被静态内置后，最后一个读取线程结束时会关闭运行库，此时另一个线程恰好开始读 RAW 就会闪退，现已改为动态库；
② libomp 默认的排队锁在 Apple 芯片上，多张照片同时解码时会卡死，现在程序启动时自动改用更简单的锁，速度不变。）RW2 解码约快 3.3 倍，DNG/ARW 约快 2 倍，解码出的像素与官方版逐位一致。

### 2. 按统一内存放开限制
- 高质量预览的最长边上限：16 GB 内存起为 8192 px，32 GB 起为 16384 px（官方对集成显卡统一限制在 6144 px，会把 6000 万像素以上的扫描压小）。
- 预览缓存随内存放大：64 GB 为 12 GB，32 GB 为 6 GB，16 GB 为 2 GB；能缓存的张数也相应增加。
- 偏好设置或 override.toml 里手动设定的值仍然优先。

### 3. 高质量预览下切换照片几乎不用等
- 内存 32 GB 起，后台以全尺寸预读前后相邻的照片。官方版预读的是小尺寸，高质量预览根本用不上。
- 内存只够放一张时，优先预读下一张。
- 预读不会把正在看的那张从缓存里挤掉。
- 能正确估算 RW2 等格式的内存用量，避免因误判内存不足而跳过预读。
- 每次预读前仍会检查系统剩余内存，电脑忙的时候自动跳过。

### 4. 三色（RGB）扫描
- 三张曝光同时解码，不再一张接一张。
- 相邻的三色组合也会被预读：官方版会跳过所有组合，现在切到三色组合时不用再等三张解码和对齐。

### 5. 大图高质量预览更流畅（1200 万像素以上，内存 32 GB 起）
- 使用与导出相同的分块方式渲染。
- 整帧分析（片基、边框、曝光范围）按原图缓存，松开滑块后不再每次重新分析。
- 原图分块常驻显卡，拖动滑块时不再重复上传。
- 以上结果都与官方的“每次重新计算”逐像素一致，由自动测试保证。

### 6. CPU 多核
- 多核 CPU 渲染在 Apple 芯片上默认开启（官方在所有 Mac 上默认关闭）；如果出现异常退出，程序会提示关闭。
- 图像格式转换（8/16 位量化、上传和读回显卡）改为多核执行，结果与单核逐位一致。

### 7. 导出 TIFF
压缩改为用满所有核心（按 64 行一条分条压缩）。9600 万像素 16 位 TIFF 的压缩约快 7 倍，解码出的像素完全相同。

## 三、没有改动的部分
- 调色、反转、色彩管理、导出结果：完全没有改动。
- 编辑记录仍保存在“文稿/NegPy”，与官方版共用（请不要同时打开两个版本）。
- Intel Mac、Windows、Linux 上的行为与官方版相同（只有 TIFF 多线程压缩和多核转换内核在所有平台生效，结果一致）。

## 四、验证
- 云端 Linux 完整测试：9221 项通过；Mac 实机（Metal GPU）完整测试：9217 项通过。
- 新增 Apple 芯片专项测试，覆盖：检测、上限、缓存预算、预读开关、受保护裁剪、三色并行一致、三色预读命中、分块渲染逐像素一致、TIFF 像素一致等。
- 移植核对脚本逐项检查 29 项优化。
