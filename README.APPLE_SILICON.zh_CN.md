# NegPy 0.65.0 中文优化版 r8

这是基于 0.65.0、提前移植的官方多语言机制，以及用户提供的 Apple Silicon 优化分支制作的独立构建，不是官方 0.66.0。

## 本次变更

- 保留动态 OpenMP LibRaw、统一内存分档、三色并行解码和 GPU 分块复用。
- 恢复平场校正强度：0–200%，默认 100%。适用于整卷默认值、单帧覆盖、预览、导出、拼接和嵌入镜头校正。强度纳入缓存身份，0% 不加载校正图。
- 解码共享有限工作线程，前台排队优先于后台；相同的并发预览解码共享只读结果。取消等待者不取消其他调用者；已进入原生解码的工作只能在安全点退出。
- Apple Silicon 的默认 OpenMP 线程预算预留交互余量，并限制嵌套并行。用户显式设置的 OpenMP 环境变量不被覆盖。TIFF 压缩默认使用部分核心，为同时调色留出余量。
- HQ 预读跟随最近的翻片方向。低内存时清理非当前画面的缓存，停止保留 GPU 原图分块，并暂停批量导出的预读；不覆盖用户偏好设置。
- 批量 TIFF 直接编码到目标目录的临时文件，完成后原子替换；编码失败不会提交半成品。ICC、元数据、位深及像素处理沿用现有路径。需要后处理元数据的特殊路径保留原有实现。
- 保留官方中文基础，单独维护摄影术语覆盖表，如暗部过渡、高光过渡、影调限定、边缘反光、识别文件内容。
- 强制打入 gphoto2 和相机驱动目录；缺少依赖时打包失败，不再静默生成没有相机模块的版本。
- 定制冻结版只打开官方更新页面，不会自动用官方二进制覆盖本版。

## r8 光学校正

- 平场总强度保留，另有“平场亮度校正”和“平场色彩校正”，均为 0–200%，默认 100%；总强度乘以分量强度。分离的是传感器 RGB 对数增益的共同分量与通道相对分量，不是简单的三个 RGB 滑块，也不保证色彩单独校正时每个物体的线性亮度不变。
- “分析平场…”在相同标尺下显示校正前后亮度不均与色彩不均，提示参考图高光溢出、噪声或纹理较强、参考增益触限与有效增益过大。它是参考图自身的诊断，不是对当前照片内容的自动判断；旧配置只有缩略参考图时可能低估噪声。
- “校准镜头色差…”从中性黑白细节参考图自动测量红/绿与蓝/绿的径向几何偏移，独立区域验证通过后才允许保存。它矫正横向色差，不是去紫边，不修复轴向色差失焦或已丢失的细节。
- 参考图须覆盖中心和四角；使用实际翻拍相机、镜头、光圈、对焦距离、放大倍率。不使用裸光源平场图或彩色负片作为色差参考。检查校正前后四角裁切图，再保存并应用；在名称中注明拍摄条件。
- 实测色差当前仅支持普通单帧 RGB，不支持拼接、HDR、三色合成和 RGB+IR；不匹配的宽高比会跳过。启用它时替代文件内嵌色差，内嵌畸变仍可单独使用。
- 镜头配置保存在用户数据目录的 `lens_ca`，编辑参数中也保存系数。升级不应删除用户数据；搬迁到另一台电脑时同时备份此目录及 `flatfield`。回退旧版不会执行新校正，重新用旧版保存编辑可能丢失新增参数。

## 相机支持边界

打入依赖不等于修复某一台相机。Sony A1 有命名驱动；普通彩色 Leica M11 没有专用命名配置，可能走通用 PTP。M11 Monochrom 是另一个型号，不能混为一谈。未连接相机进行拍摄、实时取景或文件下载验证，不承诺 A1/M11 已能联机。

可以在终端运行下列命令检查软件依赖；它不打开照片数据库，也不枚举或访问 USB 相机：

```sh
"/Applications/NegPy 中文优化版.app/Contents/MacOS/NegPy 中文优化版" --diagnostics "$HOME/Desktop/NegPy-诊断.json"
```

## 安装与回退

仅适用于 Apple Silicon Mac。本版未经 Apple 公证，可能需要在系统隐私与安全性中允许打开。安装前退出全部 NegPy，备份 `~/Documents/NegPy`，再将 App 拖到应用程序目录。本次制作过程不替换任何已安装 App，也不迁移实际照片数据库。

App 名称与已有版本不同，但默认仍共用用户数据目录，不能同时运行多个版本。回退时保留旧版 App；新版修改过的平场强度在不支持该字段的旧版中不会生效。不要在两个版本间并行编辑同一个数据库。

## 验证与性能说明

测试报告和截图另附。针对 RAW 的压力测试只读输入照片；测速与机器内存、文件格式、缓存状态及后台负载有关，不保证每个操作都比前一优化版更快。这里优先减少资源争抢和峰值内存，不改变调色算法。没有新增 RGB 单通道重建或镜头数据库。实测色差配置须由同一套翻拍设备的参考图建立，不能代替镜头数据库，也不保证不同拍摄条件下通用。

## 源码与后续移植

官方翻译仍位于 `negpy/translations`；术语修订表位于 `scripts/zh_photography_terms.json`。新增控件接入现有滑块、快捷键、整卷默认值和帮助系统。用 `make translations` 重新生成语言包时会应用术语表。

构建资料内包含经过验证的 CPython 3.13 / macOS arm64 RAW 运行库、对应 rawpy/LibRaw 和 OpenMP 源码归档、许可证。先 `uv sync --locked --group camera`，再运行：

```sh
uv run --no-sync python -m scripts.build_apple_silicon --output /absolute/path/to/output
```

构建脚本在临时目录打包，不安装 App；会验证动态 OpenMP 和相机依赖。`apple-silicon-build/mac/` 为输入分支的历史脚本，不应直接执行，其中旧脚本可能替换安装版或使用静态 OpenMP。后续以新的 r8 构建入口为准。

上游更新后，仍需要合并代码补丁和运行测试；用户配置保存在应用外，不应随升级删除。NegPy 为 GPL-3.0，第三方组件许可证见 `third_party`；未经验证不应宣称不同版本逐像素一致。
